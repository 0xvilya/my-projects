`public/scenes/tokyo-rain-v1.png`.

The original image was generated specifically for RainCode with the built-in
OpenAI Image Generation tool on 2026-10-27 from a text-only prompt. No website
photographs, third-party reference images, logos or copyrighted characters were
supplied. Original output identifier:
`exec-92e3c189-4c7e-4b6f-b1e8-13923815ac1b.png`.
